Ironpeak Fitness

A workout planner, strength tracker, and deep analytics tool — built as a native app for Android, iOS, Windows, and macOS. All your data stays 100% on your device: no cloud, no server, no account, no tracking.

Features

What's inside

Training

  • Plans by weekday or rotation — build your own, import one, or start from eight built-in templates
  • Guided workouts: set-by-set input, live session timer, RPE tracking, drag-and-drop reordering mid-session
  • Rest timer on real clock time, not a countdown — stays accurate no matter how long the screen was off
  • Progressive-overload suggestions after every logged session
  • Training calendar, workout history, and a progress-photo gallery

Strength

  • Bench Press / Deadlift / Squat: PR, history, trend chart, plateau detection
  • A plain-language strength level for every lift (Beginner → Elite), plus Total and DOTS score
  • Built-in 1RM calculator (Epley) and plate calculator

Analytics

  • Its own tab, five sections: Overview, Strength, Volume, Consistency, Achievements
  • Every number comes from real logged data — the app says so plainly when there isn't enough yet
  • Four multi-level achievement paths, calculated live from real data

Exercise database

  • 535 exercises, searchable, sorted by category, loaded live from GitHub with an offline fallback
  • An illustrated, tappable muscle-activation diagram for every exercise — front/back, male/female
  • Build your own exercise with the same editor: tap muscles directly on the figure

More

  • Apple Health / Health Connect integration
  • Daily training reminder
  • Backup & restore via text export or native share — no account, no auto-sync
  • Custom colors, automatic light/dark mode, 10 languages

Releases page →

Everything is stored only on your device. There's no server and no account — the only network calls are loading the exercise database (with an offline fallback) and checking GitHub for new releases, which you can turn off. Backups go out through your OS's native share sheet, only when you choose to send one.
